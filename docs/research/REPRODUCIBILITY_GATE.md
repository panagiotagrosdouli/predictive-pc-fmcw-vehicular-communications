# Corrected Reproducibility Gate

A final Paper-1 claim must be traceable to: the corrected commit SHA; frozen corrected protocol; development and holdout seed lists; raw paired rows; selected candidate; frozen analysis output; workflow run ID; artifact ID/name/digest; current test/CI run; manuscript revision; and generated PDF artifact.

The historical service-guard bundle remains available as provenance but is not an acceptable source for corrected headline numbers after the deadline semantics fix.

The final package must fail closed when any of these fields is absent. Negative/null corrected outcomes must be propagated to the manuscript without selective omission.
